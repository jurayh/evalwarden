# Changelog

All notable changes to evalwarden are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions are
[SemVer](https://semver.org/).

## [0.13.1] - 2026-10-09

### Added

- `evalwarden checks`: list every registered check, grouped by lane,
  straight from the registry.
- PyPI project URLs (homepage, repository, issues, evidence registry) in
  the package metadata.
- A hosted demo report card on the project site, generated by
  `evalwarden report-card` from the `judge_bad` demo fixture.
- A pre-commit hook definition (`evalwarden-audit`) so the audit can run
  before every commit.
- This changelog.

### Changed

- Adapters share one IO helper module (`adapters/_io.py`) for digest,
  JSON/JSONL reading, and timestamp parsing instead of five private
  copies; error messages are unchanged.
- Check lanes register uniformly: every lane module exports a `CHECKS`
  list. The registry still holds the same 24 checks in the same order.
- Refreshed stale module docstrings (adapter registry, engine, checks)
  to describe what actually ships.

### Fixed

- A non-UTF-8 `trajectories.jsonl` fed to the Inspect adapter now fails
  with a clean `AuditError` instead of an uncaught `UnicodeDecodeError`.

### Internal

- Smoke tests for the HTML and terminal reporters, the two output
  surfaces that previously had no direct tests.

## [0.13.0] - 2026-10-08

### Added

- Trace observatory: `evalwarden trace` reads Claude Code and Codex
  session logs and renders one local report — sessions segmented into
  phases, repeated tool calls priced as trajectory waste, with no
  upload and no rerun.

## [0.12.1] - 2026-10-08

### Changed

- Report cards render "Checks run" grouped by lane with plain-English
  labels (title first, check ID as a chip) instead of one semicolon
  paragraph; finding headlines and the "Blocked by" line lead with
  titles too. The landing page catalog uses the same ordering.

### Added

- PyPI topic classifiers for discoverability.

## [0.12.0] - 2026-10-06

### Added

- GRAD-003: isomorphic-clone verifier-gaming check — re-scores cached
  outputs against cloned tasks whose entities are renamed, reordered,
  and rescaled; a large pass-rate gap means the verifier rewards
  surface form, not success.
- Universal importer: audit canonical JSON documents, typed JSONL
  record streams, and plain CSV score tables against the versioned
  `evalwarden.model` 1.0 contract, via the CLI or the Python API.

## [0.11.0] - 2026-10-05

### Added

- Native Inspect AI `.eval` log ingest: `audit` and `report-card`
  accept a `.eval` file (or a one-log directory) directly, including
  logs written with Zstandard compression.

## [0.10.0] - 2026-10-05

### Added

- Machine-readable findings: `--format json` emits the versioned
  `evalwarden.findings` 1.0 document; `--format sarif` emits SARIF
  2.1.0. Both share one serializer with the human formats.
- A composite GitHub Action that installs evalwarden from PyPI, runs
  the audit, uploads SARIF to code scanning, and fails with the
  audit's exit code.

## [0.9.0] - 2026-10-04

### Added

- JUDGE-009: panel blind spots — failure modes no judge in the panel
  catches, measured per (judge, mode) against reference labels.
- DATA-003: elicitation coverage — declared failure modes with too few
  (or zero) eliciting items.
- NOISE lane: NOISE-001 (one noise source dominates the eval budget)
  and NOISE-002 (claimed score change versus the noise floor).

## [0.8.0] - 2026-10-01

### Added

- TRAJ lane: TRAJ-001 (trajectory repeats identical tool calls) and
  TRAJ-002 (tool outputs consumed by nothing downstream), over a new
  `TrajectoryStep` span model.

## [0.7.0] - 2026-09-29

### Added

- JUDGE-007: judge confidence calibration against reference labels.
- JUDGE-008: redundant judges in a panel — a judge that never differs
  from the rest adds no signal.
- DATA-001 (dataset saturation) and DATA-002 (near-duplicate items).

## Earlier releases

0.1.0–0.6.1 (September 2026): initial scaffold (as `evalint`), the
ENV/GRAD/COST lanes and the first six JUDGE checks, the HTML reporter
and report cards, the Inspect and Promptfoo adapters, the rename to
evalwarden, and the first PyPI releases via trusted publishing.
